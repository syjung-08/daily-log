⚙︎ 저장 위치·설정

어느 기기에서 쓰든 OneDrive의 앱 전용 폴더(OneDrive\Apps\나의하루)에 있는 월별 데이터 파일(2026-11.json 형식)을 읽고 씁니다. 앱은 이 폴더 밖의 사진·문서에는 접근하지 않습니다.

회사·집 PC용. 설치·로그인 없이 바로 사용. Edge 또는 Chrome에서 이 파일을 열어 사용합니다.

이 브라우저는 폴더 직접 저장을 지원하지 않습니다. PC의 Edge·Chrome을 쓰거나, 아래 'OneDrive 클라우드'를 사용하세요.
앱 전용 폴더를 선택하세요. 예: C:\Users\이름\OneDrive\Apps\나의하루
이 폴더는 휴대폰 등에서 처음 Microsoft 로그인할 때 자동으로 생성됩니다. 'Apps'가 '앱'으로 보일 수 있습니다.

휴대폰·태블릿·어느 PC든 사용. 앱을 웹 주소(https)에 올리고 1회 설정이 필요합니다(아래 안내).

지금은 파일(file://)로 열려 있어 클라우드 로그인을 쓸 수 없습니다. 웹 주소(https)로 연 화면에서 설정하세요.
데이터 위치: 로그인하면 표시됩니다
리디렉션 URI(앱 등록 시 'SPA'로 입력):

기기 간 동기화 없음. 써 보고 나중에 '백업 가져오기'로 옮길 수 있습니다.

📘 설정 안내 A. 회사·집 PC (바로 사용)
  1. 이 파일을 OneDrive 폴더에 저장합니다(두 PC에 자동 동기화).
  2. B의 Microsoft 로그인을 한 번 마치면 OneDrive에 Apps\나의하루 폴더가 생깁니다(먼저 B를 진행).
  3. 이 파일을 Edge·Chrome으로 열고 → 설정 → 'PC 폴더' → 폴더 선택 → OneDrive\Apps\나의하루 지정.
  4. 브라우저를 다시 켜면 상단에 '폴더 접근 허용' 버튼이 뜹니다. 한 번 눌러 주면 됩니다.
B. 휴대폰·태블릿 (1회 설정)
  1. 이 파일을 index.html로 이름을 바꿔 https 주소에 올립니다(예: GitHub Pages 무료).
  2. Azure 포털 → Microsoft Entra ID → 앱 등록 → 새 등록. 이름: 나의하루(이 이름으로 앱 전용 폴더가 생깁니다). 계정 유형: 개인 Microsoft 계정만. 리디렉션 URI: 플랫폼 단일 페이지 애플리케이션(SPA), 주소는 위 '리디렉션 URI'와 동일.
    개인 계정만 있으면 Azure 무료 계정 가입(디렉터리 생성)이 먼저 필요합니다.
  3. API 사용 권한 → Microsoft Graph → 위임된 권한 → Files.ReadWrite.AppFolder 추가(앱 전용 폴더만 접근).
  4. 개요 화면의 '애플리케이션(클라이언트) ID'를 위 칸에 붙여 넣고 → Microsoft 로그인.
  5. 휴대폰 Chrome 메뉴 → '홈 화면에 추가'로 앱처럼 사용합니다.
동시 편집 시 항목 단위로 최신 내용을 병합합니다. OneDrive가 만든 충돌 사본(예: 2026-11-PC이름.json)도 자동으로 합친 뒤 정리합니다.
